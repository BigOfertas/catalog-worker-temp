# BIGofertas Catalog Worker (temporário)

Repositório público temporário usado **somente** para processamento pesado de álbuns públicos do Google Photos com GitHub Actions.

- Não contém código do storefront BIGofertas.
- Não contém banco de dados, clientes, pedidos ou credenciais.
- Não contém `SUPABASE_ACCESS_TOKEN`, chaves da Hostinger ou outros segredos.
- Gera apenas planos JSON auditáveis a partir de álbuns públicos.
- A publicação no banco de produção é feita separadamente, fora deste repositório público.

Grupos preparados: La Liga, Serie A, Premier League, Bundesliga, Ligue 1, MLS e Outros Times.
